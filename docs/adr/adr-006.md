# ADR-006 · Modelo de búsqueda inteligente

ADR-006 · Estado: provisional, 06/11. Contexto: el caso necesita JSON acotado y continuidad sin IA. Decisión: conservar gpt-6.1-terra como candidato, sin declarar validación por adelantado. Alternativas: filtros manuales y reglas deterministas, o proveedor alternativo detrás de ModelAdapter. Consecuencias: costo y dependencia externa; fallback y evaluación previa obligatorios.

La documentación oficial consultada confirma el identificador y salidas estructuradas. El cálculo de referencia para 1.000 tokens de entrada y 300 de salida es USD 0,0025 usando USD 1 y USD 5 por millón respectivamente; es una estimación, no un gasto medido. Razonamiento, más tokens y cambios de tarifa pueden elevarlo.
