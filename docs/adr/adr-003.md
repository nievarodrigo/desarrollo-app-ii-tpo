# ADR-003 · Strategy para ordenamiento

Estado: existente. Contexto: cinco modos de orden comparten los mismos filtros. Decisión: seleccionar una función de ESTRATEGIAS_DE_ORDEN en catalogo-service-local.js. Claves reales: relevancia, precio-asc, precio-desc, rating y nombre. La actividad de IA se ajusta para usar rating, no inventar una clave puntuacion.

Alternativa: cadena creciente de if/switch mezclada con filtros. Consecuencias: comparadores intercambiables y extensión localizada; mantener equivalencia local/remota. Verificación: 25 pruebas JS de catálogo ejecutadas. Relevancia y filtros no deben depender de búsquedas previas.
