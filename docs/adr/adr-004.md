# ADR-004 · Adapter de catálogo remoto

Estado: existente. Contexto: la interfaz funciona sin servidor y dentro del WAR. Decisión: CatalogoServiceRemoto traduce buscar(criterios) a query params HTTP y transforma la respuesta a los DTO que espera la vista; la fábrica selecciona origen local o remoto.

Alternativa: fetch en cada vista; descartada por duplicación y acoplamiento. Consecuencias: se puede cambiar el origen sin reescribir la presentación; deben distinguirse 404 y fallos de red. El servicio local y remoto implementan el mismo contrato del front. La equivalencia REST está pendiente de prueba de integración.
