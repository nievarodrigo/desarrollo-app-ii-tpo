# ADR-012 · Gateway de IA y elección del modelo

Estado: implementado, 19/11/2026 (3.er checkpoint).

## Contexto

La funcionalidad de IA es la **búsqueda en lenguaje natural**: el cliente escribe "auriculares baratos hasta 50 mil" y recibe filtros del catálogo (categoría, orden, precio máximo, stock). Es una tarea corta de clasificación/extracción: ~500 tokens de entrada (prompt + esquema + consulta) y ~150 de salida (JSON + razonamiento breve, que también se cobra como salida) por consulta. Son estimaciones: el número real se mide con el conteo de tokens de la API.

## Decisión

1. **Gateway (Facade)** `GatewayIA`: única puerta hacia el modelo. Política de entrada (datos personales, inyección, monedas) → bulkhead de 4 llamadas → **timeout de 5 s** → validación estricta de la salida → **fallback** por reglas (`InterpreteDeReglas`). El usuario nunca ve un error por culpa de la IA.
2. **Adapter** `ModeloIA` con dos implementaciones: `ModeloClaude` (producción) y `ModeloLocal` (Ollama, para desarrollo y demo). Se elige con `GOMARKET_IA_PROVEEDOR` (`anthropic` por defecto, o `local`), sin tocar el gateway ni el front.
3. **Modelo: Claude Haiku 5.5** (`claude-haiku-5-5`), configurable con `GOMARKET_IA_MODELO`. SDK oficial de Anthropic para Java, salida estructurada (schema derivado del record `SalidaModelo`), `effort` bajo, timeout HTTP de 4,5 s y sin reintentos.

## Alternativas consideradas (precio por millón de tokens, entrada / salida)

| Opción | Entrada | Salida | Comentario |
|---|---:|---:|---|
| **Claude Haiku 5.5** | US$ 0,10 | US$ 0,50 | Elegido: el más barato de Anthropic, generación actual, salida estructurada nativa |
| Claude Haiku 4.5 | US$ 1,00 | US$ 5,00 | Generación anterior: 10 veces más caro para esta tarea |
| Claude Sonnet 5.5 | US$ 2,00 | US$ 10,00 | Sobra capacidad para extraer 5 campos |
| DeepSeek / MiniMax / modelos abiertos vía OpenCode u OpenRouter | ver presentación | ver presentación | Precios competitivos; se evaluaron en la presentación. Implican otro proveedor, otra política de datos y otro adapter |
| Modelo local `qwen2.5:3b` con Ollama | 0 por consulta | 0 por consulta | **Adapter de desarrollo y demo**: sin key ni internet, ~0,4 s en una GPU de 8 GB. No es la elección de producción: hay que operar y escalar el hardware, y entiende menos que Haiku (ver eval) |
| Sin IA (sólo reglas) | 0 | 0 | Es el fallback: gratis e instantáneo, pero entiende mucho menos |

Costo estimado con Haiku 5.5: 500 × 0,10/10⁶ + 150 × 0,50/10⁶ = **US$ 0,000125 por consulta** (12,5 centavos de dólar cada 1.000; US$ 125 por mes con 100.000 usuarios que hacen 10 búsquedas). El análisis completo por volumen (1.000 a 100.000 usuarios) está en la presentación del checkpoint.

## Consecuencias

- Sin `ANTHROPIC_API_KEY` el sistema funciona igual (responde el fallback, `origen: "reglas"`, `motivo: "sin-proveedor"`).
- El SDK trae Jackson: se fijó `resteasy.preferJacksonOverJsonB=false` en `web.xml` para que la API REST siga usando JSON-B.
- Verificado en WildFly con una clave inválida: el SDK carga, la API responde 401 y el gateway cae al fallback en < 1 s.
- **Modelo real verificado con el adapter local** (20/11/2026): `GOMARKET_IA_PROVEEDOR=local` con Ollama y `qwen2.5:3b`. El gateway responde `origen: "modelo"` en ~0,4 s; con Ollama apagado cae a reglas en milisegundos. Eval set: 92 % de exactitud, 100 % de adversariales resistidos y 100 % de formato válido (`entrega-3/evidencias/eval-ia-modelo-local.txt`). Falla en 2 casos razonables: "monitor premium" ordenado por valoración en vez de por precio, y un pedido ambiguo que sugiere en vez de pedir aclaración.
- El adapter local usa el mismo prompt versionado, la misma consulta delimitada y salida estructurada con el esquema de `SalidaModelo` en el **orden** de los ejemplos del prompt (con otro orden, el modelo chico dejaba `q` vacío). Mantiene el modelo cargado 30 min y el gateway lo precalienta al arrancar, porque la primera carga en la GPU tarda más que el presupuesto de 5 s.
- Prompt **busqueda-v3**: guía de categorías y palabra clave en `q`, para frases como "algo para tomar mate" o "camping". En el front, si el texto sugerido no encuentra productos se quita y quedan los otros filtros (red de seguridad ante un error del modelo). La búsqueda con IA también se dispara con el botón de la varita, sin mínimo de palabras.
- **Pendiente:** el camino con Claude Haiku contra la API (hace falta una `ANTHROPIC_API_KEY` válida). La llamada compila contra el SDK 3.3.0 y se probó con una clave inválida (401 → fallback).
- El endpoint es público: tiene un límite de 30 consultas por minuto por IP (429 + `Retry-After`) para que nadie gaste tokens en un loop (`LimiteDeConsultas`). El bulkhead limita la concurrencia; el límite, el costo.
- Bug corregido tras la verificación: una tarea que vencía mientras esperaba en la cola del ejecutor no devolvía su cupo del bulkhead; ahora el cupo se libera una sola vez, desde la tarea o desde quien llama (test `lasTareasCanceladasAntesDeArrancarDevuelvenElCupo`).
