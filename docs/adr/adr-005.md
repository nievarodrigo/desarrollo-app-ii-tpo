# ADR-005 · Facade y Adapter para IA

Contexto: una llamada al modelo mezcla protocolo, privacidad, errores y validación. Decisión: la Facade AIGateway expone interpretar(consulta); ModelAdapter traduce esa operación al proveedor. El controller sólo valida HTTP y mapea DTO. Alternativa descartada: llamar al proveedor desde JavaScript exponiendo secretos y acoplando la vista.

Consecuencias: el proveedor se sustituye detrás del Adapter, las políticas son consistentes y el gateway se prueba con un doble controlado. La referencia Python está separada de la app Java y no se presenta como despliegue real. El port a Java usará ManagedExecutorService y cliente HTTP con cancelación.
